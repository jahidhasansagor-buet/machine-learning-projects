2. QUICK SETUP (5 minutes)
═══════════════════════════════════════════════════════════════════════════

Step 1: Install Dependencies
────────────────────────────────────────────────────────────────────────────
Open terminal/command prompt and run:

    pip install -r requirements.txt

This installs:
- pandas, numpy (data handling)
- matplotlib, seaborn (visualization)
- nltk (NLP)
- scikit-learn (ML)
- gradio (web app)
- joblib (model saving)

Step 2: Download NLTK Data (Optional)
────────────────────────────────────────────────────────────────────────────
Open Python and run:

    import nltk
    nltk.download('stopwords')

Note: This is optional. The model is already trained and works without this.

Step 3: You're Ready!
────────────────────────────────────────────────────────────────────────────
The model is already trained and saved in models/best_model.pkl
You can skip directly to running the web app!

═══════════════════════════════════════════════════════════════════════════
3. RUNNING THE PROJECT
═══════════════════════════════════════════════════════════════════════════

Option A: Launch Web App Directly (RECOMMENDED)
────────────────────────────────────────────────────────────────────────────
The model is already trained! Just run:

    python app.py

Then open your browser to: http://localhost:7860

Try it out:
1. Paste a news article in the text box
2. Click "Classify Article"
3. See if it's Fake or Real with confidence scores!

Option B: Explore the Notebooks
────────────────────────────────────────────────────────────────────────────
1. EDA Notebook:
   
   jupyter notebook notebooks/1_eda.ipynb
   
   Explore:
   • Data distribution
   • Text length analysis
   • Most common words
   • Visualizations

2. Training Notebook:
   
   jupyter notebook notebooks/2_training.ipynb
   
   See:
   • Model comparison
   • Confusion matrices
   • Performance metrics
   • Model selection

Option C: Retrain the Model
────────────────────────────────────────────────────────────────────────────
If you want to retrain from scratch:

    python train_model.py

This will:
• Load the dataset
• Preprocess text
• Train Logistic Regression
• Save to models/best_model.pkl
