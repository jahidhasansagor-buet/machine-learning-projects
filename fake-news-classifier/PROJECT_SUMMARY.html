🚀 Getting Started

Quick Setup (3 Steps)

  1. Install dependencies: pip install -r requirements.txt
  2. Run the web app: python app.py
  3. Open browser: Navigate to http://localhost:7860

Note: The model is already trained! You can skip training and go straight to the web app.

💡 Key Insights

  • Fake articles are longer: Average 4,003 characters vs 2,394 for real articles
  • Language patterns differ: Fake news uses more emotional, sensational language
  • Source attribution: Real news cites sources more frequently (Reuters, AP)
  • Model effectiveness: 99.1% accuracy with minimal false positives/negatives
  • Balanced dataset: Equal representation ensures fair training
