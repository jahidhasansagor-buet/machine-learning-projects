# Machine Learning Projects

This repository contains a collection of machine learning and AI projects developed for learning, experimentation, and applied problem solving.

Projects include:

* Customer segmentation
* Brain tumor classification
* Fake news classification
* House price prediction
* Stock price forecasting
* Used car price prediction

The projects explore topics such as regression, classification, clustering, data preprocessing, model evaluation, and predictive modeling using Python and Jupyter Notebook.

This repository documents my completed machine learning projects and practical experience with data-driven modeling and AI applications.
